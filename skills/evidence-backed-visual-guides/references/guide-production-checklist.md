# Guide production checklist

## Before drafting
- [ ] Origin, dates/season, group size, duration, budget, interests, exclusions, and output path recorded.
- [ ] If a date is missing, choose a stated assumption rather than hiding it.
- [ ] Separate primary anchors from optional additions.

## Content order
1. Ranked places/experiences.
2. Ranked signature foods.
3. Day-by-day route.
4. Time, transport, accommodation, meals, budget, booking notes.
5. Cut list, assumptions, and sources.

## Fact hygiene
- Label fictional/real-world correspondences as inspiration or adaptation.
- Link official tourism and transport sources where practical.
- Mark prices, schedules, and holiday crowding as estimates that need rechecking.

## HTML QA
- Open the actual file, not only the source.
- Check heading order and mobile readability.
- Enumerate image URLs and confirm each loads; replace any 404/empty image.
- Check external links and state whether internet access is required.
- Report the absolute output path.

## Reusable pattern from the Yakuza 0/7/8 trip
A compact game-location trip worked better as a city-anchor route: Tokyo/Shinjuku, Yokohama/Isezaki-cho and Noge, Osaka/Dotonbori and Sonezaki/Minami. The itinerary explicitly labeled Kyoto and generic sightseeing as removable instead of filling seven days. Open-jaw Tokyo-in/Osaka-out avoided backtracking; the round-trip fallback was shown separately.
