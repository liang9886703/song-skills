# 中文人物影视与真人互动影游履历检索

## 适用场景

用户询问中文演员出演过哪些电影、电视剧、网剧、真人互动影游或相关综艺音乐作品，尤其适用于姓名重名、资料分散、作品类型容易混淆的情况。

## 工作流程

1. **先做实体确认**
   - 用“作品名 + 人名 + 饰演/演员”检索，确认用户所指的人物。
   - 对常见姓名核对出生地、院校、代表作或目标作品中的角色；不要把同名演员履历合并。
   - 若上下文已经给出明确作品和角色，可直接以该角色作为实体锚点。

2. **检索与交叉验证**
   - 优先使用官方作品页、游戏平台/发行商页面、主流影视平台、百科及可靠媒体报道。
   - 搜索摘要、论坛、问答和粉丝帖只作为线索；至少用另一独立来源确认关键作品或角色。
   - Exa 可用时先用 `exa.web_search_exa`；中文结果不足或服务受限时，使用百度搜索经 Jina Reader 的可读结果：
     `curl -s "https://r.jina.ai/http://www.baidu.com/s?wd=<URL编码查询>"`
   - 记录来源 URL，回答中给出简短来源说明；不要把检索摘要中的推测当作事实。

3. **按媒介整理**
   - 游戏/真人互动影像：作品名 + 角色。
   - 电视剧/网剧：作品名 + 角色。
   - 电影：作品名 + 角色；角色资料缺失则不硬补。
   - 综艺/音乐单独列出，不能当作影视出演。
   - 用户问“影游”时，优先解释其在此语境下通常是真人互动影像游戏，不要直接当成普通电影。

4. **控制结论范围**
   - 资料不完整时使用“目前公开资料显示”“目前能核实到”等限定。
   - 不要声称“全部作品”，除非使用了权威完整片目并完成交叉核验。
   - 对仅有单一低可靠来源的条目，标为待核实或省略。
   - 默认先给结论和代表作；用户未要求时不要堆砌生平、评价或无关细节。
   - **用户指出“漏了很多/信息差太多”时，视为检索口径错误信号**：不要只补用户暗示的那一部，也不要解释或辩护；重新拆分“互动影游、影视短剧、待上线项目”三类，扩展检索同演员的角色名、续作、官方宣传、Steam/发行商页面，并对新增条目做独立来源交叉核验。
   - 互动影游履历不能用传统影视百科代替；应单独检索演员名 + “互动影游/FM V/真人互动/游戏/角色”，并记录已上线、已官宣未上线、仅有线索三种状态。

## 输出模板

```text
按你说的这两位演员：

### 人物 A
- 游戏：……——……
- 电视剧/网剧：……——……
- 电影：……——……

### 人物 B
- 游戏：……——……
- 电视剧/网剧：……——……
- 电影：……——……

注：综艺、歌曲经历另行列出；以上为目前公开资料中能核实到的内容。
```

## 常见陷阱

- 同名演员的百科条目、影视平台卡片可能被搜索引擎混在一起。
- “出演过”与“参加综艺/发行歌曲”不是同一类经历。
- 百科或搜索摘要可能包含未来日期、错别字或自动生成内容，必须以作品页/平台页和第二来源复核。
- 不确定角色名时宁可只写作品名，也不要从剧情简介推断角色。
