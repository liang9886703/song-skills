# 中文人物履历检索参考

## 查询顺序

1. `作品名 + 人名 + 饰演/演员`：确认目标人物与角色。
2. `人名 + 影视作品/电影/电视剧/游戏`：补齐履历。
3. 对每个关键条目，用官方作品页、游戏平台、影视平台或第二独立来源复核。

## Exa 受限时的 fallback

```bash
curl -s "https://r.jina.ai/http://www.baidu.com/s?wd=<URL编码后的查询>"
```

百度结果适合提供候选作品和角色线索，但搜索摘要、问答、论坛或粉丝内容不能单独证明完整片目。

## 本次会话提炼的核验要点

- 《美女，请别影响我学习》是全动态真人互动影像游戏，不是普通电影；马倩倩饰演林雅，王涵饰演温苒。
- 马倩倩的公开履历可按电影、电视剧/网剧和游戏分组；她还出演过《美女，请别影响我成仙》，但每次回答都应以当前检索到的可靠资料为准。
- 王涵的公开资料同时包含《明日之子》第三季、影视作品和影游；综艺/音乐经历要与影视出演分开，不要把参加节目当成“演过的影视作品”。
- 当片目来源不完整时，使用“目前公开资料显示/目前能核实到”，避免把搜索结果拼成所谓“全部作品”。
