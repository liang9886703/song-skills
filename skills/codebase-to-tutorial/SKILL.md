# Codebase to Tutorial

这是 The Pocket 的 Codebase Knowledge Builder 的本地技能封装，不是上游发布的官方 skill。上游流程源码原样保存在 `assets/upstream/`；`scripts/run.py` 将模型请求交给当前智能体处理，无需另外配置模型 API。版本和操作见 [运行说明](references/runner.md)。

默认生成中文 Markdown 教程，入口为 `index.md`，以人的理解顺序组织。代码标识符、路径、命令和原始代码保持原样。用户指定其他语言时遵从用户。

## 工作方式

1. 确定源码和输出位置，先读项目规则、上手文档、公开接口和主要入口。已有用户指定的范围与目录就直接使用。未指定输出位置时选择项目之外的可写目录，避免污染源码或覆盖旧教程。
2. 阅读 [运行说明](references/runner.md)，用 `scripts/run.py` 启动上游原生流程：识别抽象、分析关系、安排章节、写作和组合。
3. 退出码 **75** 表示等待当前智能体提供响应。读取工作目录的 `pending.json`，按其 `prompt` 指向的提示词及所需格式生成响应，写入指定的 `response` 文件，再用相同参数运行。重复直到退出码为 0；不得把中间文件当作完成的教程交付。
4. 提示词太大时，先看 `crawl-manifest.json`，按索引提取 `crawl-files.json` 或直接读源码；准确使用文件索引。不能声称读完全部抓取源码。上游默认排除测试、文档和超过 100 KB 的文件，必要时另行补读并记录实际阅读范围。
5. 检查最终教程：章节及源码链接有效；关键行为有源码依据；示例中的省略有说明；图中顺序、条件和方向与实现相符。未经运行不声称代码可直接执行。把检查与限制补入 `run-report.md`，交付教程目录链接。

## 内容要求

- 从读者要完成的任务或一个具体例子讲起，解释解决什么问题、对象怎样协作、沿哪些源码继续读。核心概念优先，章节数随项目规模调整。
- 除正常路径外，解释该主题的重要分支、错误和生命周期边界。图谱邻接不能当作真实执行时序。
- 示例展示关键代码，链接到真实文件和声明位置；示意图聚焦少量概念，显示标签使用中文。
- `index.md` 和章节是主体，扫描快照、模型请求和中间 JSON 留在工作目录。
- 用户指定原生外部模型方式时，可用附带的上游入口及原始依赖；宿主适配不等于已配置或验证外部模型。
