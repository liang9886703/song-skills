Simon Willison / Qwen读权重.md

笔记本上的 Qwen 3.8 也能读模型权重

Simon Willison · 2026-11-03

Takehi 等人那篇「权重空间编程」火起来之后，Simon 拿本机 Qwen 3.8 27B 复现：模型能直接读、甚至改一段浮点权重文本。不是只有 GPT‑6 Astra 才干得了。

深入分析

论文形状的博客演示 frontier 模型把神经网络权重当一等公民读写。Simon 用本地 27B 跑通同类例子，说明「看懂权重」这条能力正在从闭源前沿往可本地跑的开源模型下沉。

对做本地 agent / 工具链的人：权重解释不再绑定某一家 API。但演示仍偏玩具与小模型；真要改大模型权重、还要验证行为，工程差距还在。

OpenAI News / 物理世界工程.md

OpenAI 把模型推进物理产品工程

OpenAI News · 2026-11-03

机械、电气、系统端到端：Astra/Codex 帮忙画外壳、布 PCB、写固件。内部硬件团队 token 用量自二月起涨了约 23 倍；对外拉赛车队和马自达做真实工程协作。

深入分析

Astra 端到端造设备

两人副业一周用 Astra 定义需求并设计外壳/PCB/固件，对接 Codex 对话设备；代工厂一个月内打小批量样。制造公差、装配细节仍要多轮人工，模型还不会「一次过产」。

评测与合作

BenchCAD 2.0 测 3D 件与电路连接识别；内部新模型均分 0.875，高于 GPT‑6 Astra 最高推理档的 0.594。Chip Ganassi 用扫描→可编辑 CAD；马自达用仿真探空气动力学与碰撞安全。

对 agent runtime：computer use + 专业 CAD/ECAD 工具链是下一块硬骨头；评测已经从纯代码扩到工程图纸。

Google Developers / 按任务成本路由.md

别看 token 价，看「做成一题」花多少

Google Developers Blog · 2026-11-03

自主 coding agent 账单在涨：真正该盯的是 cost per successful task。用便宜分类器（文中举例 Jev）把简单题打到 Flash‑Lite，难题再升 Flash low thinking。

深入分析

正则/字数启发式在手里 16 题很好看，到 34 道未见题准确率掉到约 70%；原子化 yes/no（Noul）分类器在未见题 34/34。砍 maxOutputTokens 当「少想一点」是错的——上限不是思考预算旋钮，只会截断难题。

无路由最强基线是 Flash + low thinking 全对；路由到 Flash‑Lite→复杂再升，也能全对且更省时。长上下文 agent 慎频繁换模型，否则 Context Caching 折扣会废。指标口径：成功任务总成本，不是每百万 token。

Google DeepMind / Antigravity化学信息学.md

Antigravity + 化学信息学 Skills：一小时走完数天药化循环

Google DeepMind · 2026-11-03

给 Google Antigravity 挂上 Cheminformatics Skills（RDKit / ChEMBL / PubChem）：文献里捞分子、配对分析、建药效模型、提合成路线。肺癌药案例里，原先数天的一轮压缩到约一小时。

深入分析

分工清楚：语言模型管编排与推理，确定性化学工具做计算。展示刚性化（crizotinib→lorlatinib 类）的匹配分子对分析、交互式浏览、反应机理图。

边界写得很硬：稀疏数据与实验噪声限制预测精度，输出是可验证假设不是成药。Skills 插件形态对 agent runtime 很有参考——领域工具封装成 skill，而不是把化学逻辑塞进 prompt。

GitHub Trending / agent-desktop.md

vercel-labs/agent-desktop：无障碍树版电脑操控

GitHub Trending · 2026-11-04

Trending 日榜。CLI/C 库/MCP：读桌面 App 无障碍树成带 ref 的 JSON，点按对着 ref，不靠截图像素。循环在调用方，库里没有模型。

深入分析

在干什么

编译期按 OS 选 AX / UI Automation / AT-SPI。默认无头动作；ref 绑 snapshot，过期返回 STALE。自带 skills 教 agent 观察→行动→再观察；`agent-desktop mcp` 暴露全套命令。

仓库初识（taste-project）

报告目录 intermediate/repos/vercel-labs-agent-desktop/。主线 crates/{core,macos,windows,linux,ffi} + skills。边界：隐私内容可能进 snapshot；自定义绘制控件可能不在树上。

Agent/MCP → CLI或FFI → core → PlatformAdapter → OS AX
← JSON envelope（ok / data / error.disposition）
